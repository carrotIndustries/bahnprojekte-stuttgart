## Temporäre S-Bahn-Verlängerung nach Horb

Als Ausgleich für den Wegfall der umsteigefreien Verbindung von der Gäubahn
zum Hbf bis zur Inbetriebnahme des Pfaffensteigtunnels soll die S1 temporär weiter
[bis nach Horb verlängert werden](https://region-stuttgart.ratsinfomanagement.net/vorgang/?__=UGhVM0hpd2NXNFdFcExjZQVJBu-jKCIGX_YehuPfKbY)
